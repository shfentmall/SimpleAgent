# v0.1.0（2026-09-18）

第一个能日常用起来的版本。核心机制（agent loop、工具、权限、会话）已经打通，
终端、浏览器工作台、无人值守三条路都能跑真实任务。对应里程碑 M0–M3，外加工作台 W1–W5，
以及 M8 里「外部 agent」提前做掉的那一半。

## 这一版能做什么

### 终端对话

- `sa` 进 REPL，流式输出，支持思考内容显示、token 用量统计、Ctrl+C 中断当前回复。
- `/model` 切换模型 profile（历史保留）、`/tools` 列工具、`/usage` 看用量、`/clear` 清空历史。
- 只依赖 OpenAI 兼容协议，配置里预置了 DeepSeek、GLM、通义千问、本地 Ollama 等 profile；
  各家的差异（思考字段名、缓存命中字段、私有参数）走 `quirks` / `extra_body` 抹平。

### 工具调用和 agent loop

- 7 个内置工具：`list_dir`、`read_file`、`write_file`、`edit_file`、`glob`、`grep`、`bash`。
- 循环自己手写：只读工具并行执行、含写工具串行执行；工具报错原样回给模型让它自救；
  一轮最多请求模型 `max_steps` 次（默认 20）；Ctrl+C 打断后会把历史修成合法状态再退出。
- 过长的工具输出只把开头回给模型，完整内容落盘到 `~/.simpleagent/tool_outputs/`（保留 7 天）；
  `read_file` 自己分页。
- 每次请求和响应都记录在 `~/.simpleagent/traces/`，方便对着协议排查。

### 权限

- 判定和询问分成两层：读操作直接放行，写文件 / 改文件 / 跑命令默认询问，
  越出工作目录和明显危险的命令（`rm -rf ~`、`mkfs`、`curl … | sh`、fork bomb 等）直接拒绝。
- 拒绝理由回给模型，它通常会自己换个办法。
- API key 只从环境变量或 `~/.simpleagent/.env` 读，不进配置文件、不进 trace；
  `bash` 启动子进程时会把这些 key 从环境里摘掉。

### 会话和无人值守

- 会话存成 JSONL，`sa sessions` 列出、`sa --resume [id]` 接着聊。
- `sa run "任务"` 跑完即退出，适合 cron / launchd。没人能确认，所以写操作一律拒绝，
  要放行用 `--allow bash,write_file` 逐个列出。

### 浏览器工作台（`sa serve`）

- 本地 HTTP + SSE 服务，零第三方依赖（标准库 `http.server` 手写路由和事件流），
  默认只监听 `127.0.0.1:8384`；断线重连靠 SSE 原生的 `Last-Event-ID` 重放。
- **空间**：一类任务一个容器。「通用」空间自动分配 tmp 目录，「绑定目录」空间进真实项目目录干活；
  每个空间默认只显示最近 5 个会话，置顶和运行中的不占名额。
- **右栏**：对话、变更、文件、日志四个 tab，工具调用和审批都是卡片；支持停止、重跑、导出 Markdown。
- **验证状态**：空间可配验证命令（如 `uv run pytest -q`），用退出码判定；
  验证通过后若文件又被改动，状态降级为「已失效」，靠目录指纹判断，不会骗人。
- **控制面板**：跨空间看正在跑和最近完成的任务，`@空间名 任务描述` 直接下发；
  消息栏收脚本投来的结论（点开 30 分钟后自动归档）；还有一个待办列表。

### 调度外部 agent

- 空间的执行者可以选 `claude-code` 或 `opencode`，以无头模式拉起，
  它们输出的 NDJSON 被翻译成本项目自己的事件，总线、存储、前端完全不用知道对面是谁。
- 记住对面返回的 session id，下次追问带 `--resume` / `--session` 接上；
  取消时杀整个进程组（这两家都会自己 fork 子进程）。
- 权限两档：`safe` 只读（默认）、`full` 全放行（界面标红）。

### 给 sa 发消息

- `sa inbox push -t 标题 -b 正文`，或者管道 `./nightly.sh 2>&1 | sa inbox push -t 夜间任务`，
  不需要 `sa serve` 在跑；也可以 `POST /api/inbox`。详见 [给 sa 发消息](../send-message.md)。

## 安装

```bash
uv tool install --editable .     # 仓库根目录执行
sa --version
sa init                          # 生成 ~/.simpleagent/config.toml
```

完整步骤和换模型的说明见 [README](../../README.md)。要求 Python 3.12+（uv 会自动准备），
运行时依赖只有 `openai` 和 `pydantic` 两个。

## 已知限制

- **还没有定时任务**：`sa daemon`、`schedules.toml`、通知推送都在 M4，这一版要自己配 cron / launchd。
- **权限规则还没进配置文件**：哪个工具属于哪一档写死在代码里，不能在 `config.toml` 里
  写「这个项目 bash 全部放行」；`--allow` 只认工具名，不支持模式匹配。
- **外部 CLI 没有实时审批**：Claude Code 和 OpenCode 的无头模式没法把「要不要批准」问回来，
  所以只能事先定 `safe` / `full` 两档。真正的实时审批要等接上 MCP。
- **Claude Code 适配只实测过失败路径**（本机未登录），成功路径的事件形状是照文档写的，
  登录后要补一份样本回归。
- **控制面板的「近期完成」还没接到前端**：接口已经返回，界面暂时只显示正在跑的任务。
- MCP、上下文压缩、记忆、Skills、子 agent 都还没做，见 [路线图](../ROADMAP.md)。
